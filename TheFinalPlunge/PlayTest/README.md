# The Final Plunge

A 2D space exploration, vessel engineering, and orbital mechanics simulator built with React, TypeScript, and HTML5 Canvas.

## Play Online
Visit the live game: [The Final Plunge](https://kenttk421-private.github.io/)

## Overview
- **Orbital Mechanics**: Patched conics, Keplerian orbits, and dynamic celestial bodies.
- **Vessel Assembly Building (VAB)**: Build, stage, and test custom multi-stage rockets.
- **Flight Simulator**: Atmospheric drag, thrust vectors, staging, and real-time telemetry.
